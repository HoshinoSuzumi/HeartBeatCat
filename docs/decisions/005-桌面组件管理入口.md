# 005 — 桌面组件管理入口

**日期**: 2026-10-02

**状态**: 已通过

## 背景

插件详情页的“桌面组件”标签主要展示窗口尺寸、置顶和透明背景等插件声明参数。用户常用的大小、透明度与点击穿透调节位于另一个“设置”标签，需要来回切换。

## 决定

将桌面组件的显示状态、开关和通用外观交互控件集中在“桌面组件”标签。仅在插件提供自定义设置，或没有桌面组件与推流能力时显示“设置”标签；插件自定义设置仍留在该标签。

## 原因

用户管理桌面悬浮窗时，能在同一处完成开启、调整和了解点击穿透的操作。插件声明的窗口参数不是用户可调整项，不应占用主要界面。

## 影响

- 正面影响：常用操作更集中，点击穿透及拖动的关系更清楚。
- 代价：原先在“设置”中寻找通用控件的用户需要适应新入口。
- 后续事项：如新增桌面组件运行时选项，优先放在“桌面组件”标签。

## 备选方案

- 保留“设置”中的控件，在“桌面组件”标签增加跳转：仍需切换标签才能调节。
- 两处同时提供相同控件：会增加重复界面和维护成本。
