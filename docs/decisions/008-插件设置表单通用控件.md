# 008 — 插件设置表单通用控件

**日期**: 2026-10-02

**状态**: 已通过

## 背景

插件设置表单根据 Schema 渲染枚举、数字、布尔和文本字段。布尔字段已经使用通用开关，其他字段仍各自使用原生元素和局部样式，视觉及值转换规则不统一。

## 决定

在 `src/components/` 中提供 `UiSelect`、`UiNumberInput` 和 `UiTextInput`，与现有 `UiToggle`、`UiSlider` 一起作为项目通用表单控件。三个新控件共用 `.ui-field` 样式。`PluginSettingsForm` 负责把 Schema 字段映射为控件及更新配置，控件负责输入细节与类型转换。

## 原因

统一样式与输入行为后，插件表单新增字段时不必复制页面样式。选择项保留字符串或数字原值；数字输入为空时不写入错误的 `0`。

## 影响

- 正面影响：设置表单的输入框和下拉菜单风格一致，可在其他页面复用。
- 代价：增加三个组件和一条共享样式规则。
- 后续事项：新增表单控件时沿用相同的焦点、禁用和标签规范。

## 备选方案

- 将所有类型塞进一个动态输入组件：组件接口和类型分支会变复杂。
- 只在 `PluginSettingsForm` 内添加统一 class：无法复用输入行为与选项类型转换。
