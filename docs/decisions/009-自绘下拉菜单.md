# 009 — 自绘下拉菜单

**日期**: 2026-10-02

**状态**: 已通过

## 背景

插件设置的枚举字段使用 WebView 原生 `select`，展开列表的外观受系统控制，无法与其他通用控件保持一致。详情面板可滚动，普通绝对定位菜单也可能被裁切。

## 决定

`UiSelect` 使用按钮和自绘选项层实现下拉菜单。选项层通过 `Teleport` 渲染到页面顶层，按触发按钮定位，并在滚动或窗口尺寸变化时更新位置。组件提供列表框语义、方向键、Home/End、Enter、Escape 与外部点击操作。

## 原因

页面可以统一控制触发按钮、选项、选中态和焦点样式，同时避免菜单被插件详情面板的滚动容器裁切。

## 影响

- 正面影响：下拉列表与其他设置控件风格一致，键盘和鼠标均可使用。
- 代价：组件需要维护菜单定位、焦点与关闭逻辑。
- 后续事项：若设置面板引入模态层，需检查菜单层级与焦点管理。

## 备选方案

- 继续使用原生 `select` 并仅修改关闭态样式：展开列表仍由 WebView 绘制。
- 在输入框下方直接绝对定位：菜单可能被右侧滚动区域裁切。
